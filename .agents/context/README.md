# Project Context — Power BI DZ Webinar Landing

Single-file RTL Arabic (Darija) landing page for a free Power BI webinar for Algerian shop owners / e-commerce / PME.

## How to use this context
1. Read `config.md` for maintenance rules (automatic, minimal, project).
2. Read `structure.md` to select relevant files per task.
3. Read `architecture.md` for page structure, styling and JS behaviors.
4. Always verify against `index.html` (source of truth).

## Files
- `config.md` — update mode / detail level / scope.
- `structure.md` — context organization contract.
- `architecture.md` — stack, page sections, conventions, critical workflows.

No `domains/` — scope is `project` only.
